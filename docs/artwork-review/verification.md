## Not verified

- GitHub Actions on this branch. Local commands are not a CI result.
- GitHub Pages deployment. The live site is unchanged until a maintainer deploys `main`.
- A browser that has never downloaded the site, opened with the network disabled. Generator offline is not a first-visit offline app.
- A separate automated race that fires two image callbacks in a fixed order. The page uses a generation token and an image token; that race was not given its own stable test.
- Physical phone, tablet, and zoomed-browser passes beyond the 320, 390, and 1440 Playwright viewports.
- Real Wikimedia cover latency. The success and failure states used a local fixture image.

## Remaining limits

- The lexicon does not understand a plot. It keeps an abstract plate when the local summary has no reliable motif.
- Unverified remote covers stay in the data and are not the main image. No Wikimedia files were mirrored.
- A rapid local `/api/random` can exceed five seconds while SQLite or artwork files are busy. The browser smoke now waits 30 seconds for that assertion. This is not a change to the draw rules.
